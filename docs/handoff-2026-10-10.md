## What Atlas is

Atlas is a desktop web browser for one person (the owner), Windows 11 only
in v1. It has a vertical-tab sidebar and a central command palette (Ctrl K),
and three built-in plugins that open as tabs: Forge (code, in PyCharm's
spirit), Notes (an Obsidian-compatible markdown vault) and Fledge (the
owner's business software). Performance is the deciding goal. Rust owns all
state and logic.

## Rules you must keep

- **Ask before you decide.** Put every undecided product question to the
  owner with your recommendation. Explain concepts briefly, because the
  owner is new to web view embedding and plugin architectures. Never
  re-litigate a recorded decision without the owner's yes.
- **Commits and pushes.** Commit only when the owner asks; the plan file may
  be committed as it is updated. No pushes and no remote until the owner
  sets them up. Never force-push, rebase shared branches or delete branches.
- **Hands off Google's pages.** On page web views, never set a custom user
  agent, attach an IPC handler, inject scripts, filter requests or open a
  debugging port. WebView2 presents itself to Google as Chrome by default,
  and that is why sign-in works.
- **The owner's accounts.** Never enter, store or ask for the owner's
  credentials. Only the owner signs in to real accounts. Never put real
  personal data (history, bookmarks, page text, cookies) in tests, logs,
  commits or chats.
- **Licences.** No GPL code until the owner picks a licence. That includes
  Zed's editor crates.
- **Windows settings.** Never change Smart App Control or any Windows
  security setting. Unsigned debug builds are blocked on this machine, so
  build with a release-style profile (D38).
- **Privacy.** No telemetry, crash dumps stay local, SmartScreen stays on.
  Never put the database in a synced folder.
- **Fledge.** Atlas is separate from Fledge. Never touch Fledge's
  repositories or call its production services.
- **Writing.** Commits, plans and issues explain why before what, name
  files and decisions (for example D13), and are readable by someone with
  no context.
