Syrinx for Linux
================

Syrinx is a browser-first workspace: a web browser with a vertical-tab sidebar
and a command palette. This folder is the portable Linux package.

What you need
-------------

- An x86-64 Linux desktop with an X11 session, or XWayland under a Wayland
  compositor such as GNOME, KDE or Hyprland.
- WebKitGTK 4.1 (2.38 or newer), GTK 3, libsoup 3 and bubblewrap, which is
  WebKit's page sandbox. Package names:
    Arch, Omarchy:   webkit2gtk-4.1 gtk3 libsoup3 bubblewrap
    Debian, Ubuntu:  libwebkit2gtk-4.1-0 libgtk-3-0 libsoup-3.0-0 bubblewrap
    Fedora:          webkit2gtk4.1 gtk3 libsoup3 bubblewrap
- GStreamer and its media plugins. WebKitGTK uses these for audio and video;
  missing autoaudiosink (in the good set) can abort a page's web process,
  even on a muted video page. Install these runtime packages too:
    Arch, Omarchy:   gstreamer gst-plugins-base gst-plugins-good
                     gst-plugins-bad gst-libav
    Debian, Ubuntu:  gstreamer1.0-plugins-base gstreamer1.0-plugins-good
                     gstreamer1.0-plugins-bad gstreamer1.0-libav
    Fedora:          gstreamer1 gstreamer1-plugins-base gstreamer1-plugins-good
                     gstreamer1-plugins-bad-free gstreamer1-plugin-libav
  If available, check the audio-sink element with:
    gst-inspect-1.0 autoaudiosink
  Debian/Ubuntu provide this command in gstreamer1.0-tools. The check does
  not verify every decoder or a working audio device. Codec availability
  depends on the distribution's plugin builds.
- Protected video (Disney+, Hulu) does not play: WebKitGTK has no Widevine.

Install
-------

Run, as yourself and not with sudo:

    ./install.sh

It warns without stopping if its WebKitGTK or autoaudiosink probe fails.
The media probe runs only when gst-inspect-1.0 is available.

It checks every file against SHA256SUMS, then copies:

    syrinx          to ~/.local/bin/syrinx
    syrinx.desktop  to ~/.local/share/applications/syrinx.desktop
    syrinx.png      to ~/.local/share/icons/hicolor/256x256/apps/syrinx.png

(~/.local/share is $XDG_DATA_HOME when that is set.) Nothing outside your home
folder changes, and Syrinx is not made your default browser. Syrinx keeps its
data in ~/.local/share/Syrinx/data.

You can also run ./syrinx straight from this folder without installing.

Update
------

Syrinx does not update itself on Linux yet. Download the new version from
https://syrinxapp.dev, check it against the release's SHA256SUMS.txt, unpack
it and run its install.sh. Your tabs, bookmarks and sign-ins stay.

Linux packages are not signed yet. The checksums show that a download is
complete, not who made it, so download Syrinx only from syrinxapp.dev.

Uninstall
---------

    ./uninstall.sh

It removes the three files above and keeps your data. To erase your data too,
delete ~/.local/share/Syrinx/data yourself afterwards.
